FAQ

Vos questions

Où est l’argent pendant la livraison ?

Il est encaissé par notre prestataire de paiement Mobile Money et enregistré dans le compte de séquestre de la commande. Personne ne peut le toucher tant que le client n’a pas donné son code ou qu’un litige n’est pas tranché.

Que se passe-t-il si le client refuse le colis ?

La commande passe en litige et l’argent reste bloqué. Notre équipe écoute les deux côtés. Si le colis était conforme, vous êtes payé ; sinon le client est remboursé, et le livreur garde le prix des trajets qu’il a vraiment faits.

Quand est-ce que je reçois mon argent ?

Le versement vers votre MTN MoMo ou Orange Money part automatiquement dès que le livreur saisit le bon code du client.

Le vendeur peut-il voir le code du client ?

Non. Le code s’affiche uniquement sur le téléphone qui a fait le paiement. Ni le vendeur ni le livreur ne peuvent le voir.

Mon client n’a pas Telegram. C’est un problème ?

Non. Seuls le vendeur et le livreur utilisent Telegram. Votre client reçoit un simple lien (par WhatsApp, SMS, Messenger) qui s’ouvre dans n’importe quel navigateur.

Dans quelles villes ?

Livraison moto dans la même ville à Douala, Yaoundé, Bamenda, Buea et Bafoussam selon les livreurs inscrits, et entre villes via les agences de voyage.
